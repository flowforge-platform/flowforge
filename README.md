# FlowForge

A Distributed Workflow Orchestration Platform inspired by Temporal, Netflix Conductor, and n8n.

## Overview

FlowForge enables users to visually create, execute, schedule, and monitor workflows through a DAG-based workflow engine and distributed worker architecture.
